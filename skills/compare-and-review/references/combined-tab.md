# Combined tab

Write this as an HTML fragment in this order. Use these classes, which the template styles: `verdict`, `odds`, `tw`, `note`, `win a` (skill), `win b` (no skill), `win t` (tie). Wrap every table in `<div class="tw">`.

1. **Verdict box:** which side won, the percentage split, why, and when you'd pick the other side.
2. **Three headline numbers:** in `<div class="odds">`, with a `<b>` figure and `<span>` label in each child.
3. **Combined metrics table:** one row per metric, with a Better column. Mark each row as measured or judgement where that isn't obvious.
4. **Why the winner won:** two to four short bullets. Add "where the skill's format worked against it" if that applies.
5. **Disagreements:** what the two sides disagreed on, what you rechecked, and your conclusion.
6. **Best combined result:** the merged output itself, such as the best emails or the combined answer. This is often the most useful part of the page.
7. **Limits of this test.**

Write for someone deciding whether to use the skill. Lead with the conclusion, use plain words, and don't repeat the same number in several places. Add a chart only if a table can't show the point.
